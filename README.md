## 📖 Sobre o projeto

O **Geometria Quest** é um projeto educacional criado com o objetivo de ajudar estudantes a aprender e praticar conceitos de geometria, especialmente conteúdos relacionados a ângulos.

A ideia surgiu da necessidade de tornar o estudo da matemática mais interessante, interativo e menos cansativo, principalmente durante a preparação para provas escolares.

Em vez de utilizar apenas listas tradicionais de exercícios, o projeto busca trazer elementos inspirados em plataformas de aprendizagem gamificadas, como sistemas de XP, progressão e acompanhamento do desempenho, aproximando o aprendizado de uma experiência de jogo.

O projeto foi desenvolvido com auxílio do Claude, utilizando inteligência artificial como ferramenta de apoio durante o processo de criação, desenvolvimento e construção da experiência.

---

## 🎯 O problema

A matemática é uma das disciplinas em que muitos estudantes encontram dificuldades durante o período escolar.

Em conteúdos como geometria, não basta apenas memorizar fórmulas. É necessário compreender os conceitos, identificar relações entre elementos e praticar diferentes tipos de exercícios.

Entretanto, muitas vezes o processo de estudo acaba sendo limitado a:

- 📄 Listas repetitivas de exercícios.
- 📚 Leitura de conteúdo sem interação.
- 🧠 Memorização de fórmulas sem compreensão.
- 😴 Métodos de estudo pouco estimulantes.
- 📉 Dificuldade em manter a motivação durante a preparação para provas.

Esses fatores podem fazer com que estudar se torne uma tarefa cansativa, dificultando a concentração e a continuidade do aprendizado.

---

## 💡 A solução

A proposta do **Geometria Quest** é transformar a prática de geometria em uma experiência interativa inspirada em jogos e plataformas de aprendizagem.

O projeto utiliza elementos de gamificação para estimular o estudante a continuar praticando, criando uma experiência em que o aprendizado está associado à progressão e à conquista de objetivos.

A ideia é que o estudante não apenas resolva exercícios, mas tenha uma sensação de evolução conforme pratica e melhora seu conhecimento.

### 🕹️ Como a gamificação ajuda?

A gamificação utiliza elementos comuns de jogos em contextos que não necessariamente são jogos, como educação, produtividade e aprendizado.

No Geometria Quest, essa proposta é representada por elementos como:

- ⭐ **XP (Experience Points):** representação de progresso e experiência adquirida.
- 🔥 **Sequência de estudos:** elemento visual de continuidade e incentivo à prática.
- 🎮 **Experiência interativa:** uma proposta de aprendizado diferente de uma lista tradicional de questões.
- 🧠 **Prática de geometria:** foco no desenvolvimento do raciocínio matemático.

O objetivo desses elementos é tornar o aprendizado mais atrativo e incentivar o estudante a continuar praticando.

## 🚀 Como executar localmente

Você pode executar o projeto em sua própria máquina para estudar, modificar ou contribuir com melhorias.

### 1️⃣ Clone o repositório

```bash
git clone https://github.com/LGA1155dev/questmath.git
```

### 2️⃣ Entre na pasta do projeto

```bash
cd questmath
```

### 3️⃣ Abra o projeto

Como o projeto possui sua implementação concentrada no arquivo HTML principal, você pode abrir o `index.html` diretamente no navegador.

Ou utilizar um servidor local com Python:

```bash
python3 -m http.server 8000
```

### 4️⃣ Acesse pelo navegador

```text
http://localhost:8000
```
